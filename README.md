## 🚀 Overview

This repository hosts the official landing page and digital portal for **Techfest 2026** at the **Indian Institute of Technology Bombay**. Engineered with a high-performance **2D aesthetic** (zero heavy 3D assets/loaders required), the site delivers sub-second load times, smooth 60fps animations, procedural audio design, and interactive accreditation tools.

---

## ✨ Key Features

- **Interactive 2D Constellation Canvas**: Real-time canvas mesh with magnetic cursor repulsion and click shockwave ripples.
- **Procedural Cyber Web Audio Synthesizer**: Zero external audio files; generates real-time UI clicks, hover chirps, and an interactive 128 BPM Technoholix synth beat directly via the Web Audio API.
- **Technoholix Stage Simulator**: Interactive neon spectrum visualizer simulating 40W lasers, 500-drone sky formations, and live audio equalizers.
- **Holographic Cyber Pass Generator**: Live custom attendee badge generator featuring an algorithmic 2D matrix QR code drawn in real-time, copyable credential IDs, and confetti bursts.
- **Arenas & Verticals Matrix**: Interactive exploration of Robowars (60kg Heavyweight), International Tech Expo, Keynote Lectures, Hackathons, and Hands-on Workshops.
- **3-Day Festival Chronicles**: Chronological timeline of events across campus venues (Convocation Hall, Gymkhana Grounds, VMCC).
- **Campus & Accommodation Guide**: Logistics, dining mess info, and transport routes to the 550-acre IIT Bombay Powai campus.
- **Patronages**: Official recognition badges from UNESCO, UNICEF, Make in India, Digital India, and SAARC.
- **End-to-End Registration Modal**: Multi-category registration with instant reference code generation (`TF30-REG-XXXX`).

- **Framework**: React 18

- **Audio**: Web Audio API (Pure procedural synthesis)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/BhavyaKansal20/techfest-website.git
cd techfest-website

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build optimized static bundle
npm run build

# Preview production build locally
npm run preview
```

## 🏛️ About Techfest IIT Bombay

Established in 1998, Techfest is the annual science and technology festival of the Indian Institute of Technology Bombay. Drawing an annual footfall of over 175,000+ students and professionals from 2,500+ colleges across India and 60+ countries, it stands as Asia's premier student-led innovation festival.
